Method: acting at test time

1. Set target R̂

e.g. an expert score

2. Model outputs aₜ

from the last K steps

3. Environment

returns sₜ₊₁ and rₜ

4. R̂ ← R̂ − rₜ

append, repeat

Analogy: a GPS. The remaining distance shrinks after each turn, and the route is recomputed from where you are.

The target return is a dial: raise it to ask for better behavior.

It is hand-picked per task. On Atari the authors used about 1× or 5× the best return in the dataset.

Chen et al., NeurIPS 2021

6 / 9

About 50 seconds. "At test time you choose a target return, say an expert-level score. The model outputs an action, the environment gives back a new state and a reward, and you subtract that reward from the target before the next step. Like a GPS, the remaining distance shrinks and the route is recomputed from where you are. The target is a dial you set by hand; on Atari the authors used roughly 1 times or 5 times the best return in the dataset, depending on the game."
