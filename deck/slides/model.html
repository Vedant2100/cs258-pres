5 / 9

About 1 minute. "The model takes the last K timesteps, so 3K tokens. Each token type gets its own linear embedding, a conv encoder for Atari frames, plus a learned timestep embedding. A GPT with a causal mask processes them, and the output at each state token predicts the action. The loss is just prediction error on the logged action. There is no Bellman update anywhere. In course terms this is behavior cloning, conditioned on return, rather than Q-learning or actor-critic. The causal mask means it only looks back at history and only predicts forward." Details if asked: K = 30 on Atari except Pong, which uses 50; K = 20 on the Gym tasks.
