Conclusion

Takeaways

  • Offline RL can be posed as supervised sequence prediction, with no Bellman backups.
  • Return-to-go is a prompt: set the goal at test time.
  • Strong at long-term credit assignment and sparse reward.

Limitations

  • The target return is hand-picked per task.
  • One fixed target fits stochastic outcomes poorly; the authors suggest modeling return distributions.
  • Can trail TD methods on some tasks (Qbert).
  • No convergence guarantee like tabular Q-learning’s; long contexts cost compute.
  • Later work questions how well it stitches sub-optimal trajectories.

The thread: credit is computed backward once, in hindsight; actions are generated forward. But that backward pass stays inside each trajectory, which is why DT can’t stitch.
